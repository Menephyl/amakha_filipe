# 📄 Landing Page — Amakha Paris
![alt text](flat-devices-mockupmakha.png)

## 🧩 Visão Geral


Landing page promocional desenvolvida para divulgar a oportunidade de negócio da **Amakha Paris**, com foco em atrair novos consultores por meio de cadastro gratuito e apresentação dos benefícios da revenda de produtos.

A página destaca:

- Oferta de **50% de desconto** nos produtos
- Potencial de **lucro de até 200%** na revenda
- Cadastro gratuito com link direto para o escritório virtual
- Apresentação institucional da Amakha Paris e seus diferenciais

## 🌐 Link de acesso

🔗 [amakha-filipe.vercel.app](https://amakha-filipe.vercel.app/)

## 🚀 Tecnologias utilizadas

- **HTML5** — estrutura da página
- **CSS3** — estilização visual
- **JavaScript** — interações básicas (opcional)
- **Git** — Versionamento de código
- **Vercel** — hospedagem e deploy contínuo

## 📸 Conteúdo visual

A página utiliza imagens ilustrativas para reforçar a proposta:

- Foto do consultor Filipe
- Imagem da fábrica da Amakha Paris
- Produto destaque: Luva de Silicone

## 🧱 Estrutura da página

- `Header`: título e chamada principal
- `Seção de cadastro`: botão com link direto para o escritório Amakha
- `Sobre a empresa`: missão, valores e histórico
- `Produtos`: destaque para itens de consumo e revenda
- `Depoimento`: apresentação pessoal do representante
- `Call to Action`: reforço para cadastro gratuito
